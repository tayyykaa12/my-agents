# Брендбук mpk-invest

Полный брендбук клиент пришлёт позже. Пока здесь только логотип.

## Логотип
- Файл: `logo.jpg` (350×259 px, JPG, на тёмно-сером фоне).
- Использовать в публикациях обязательно.
- Знак: буква «М» (или «И»/«N») из четырёх цветных полос. Справа надпись «МПК ІНВЕСТ» белым, украинское «І».
- **Нужно уточнить у клиента:** логотип в векторе (SVG, PDF или AI) или PNG с прозрачным фоном. Этот файл маленький и на сером фоне, поэтому его нельзя поставить на светлый слайд или увеличить без потери качества. Нужна также версия логотипа для светлого фона.

## Цвета логотипа
Цвета сняты кодом с картинки (средние значения). JPG искажает цвета, поэтому точные HEX нужно сверить с брендбуком.

| Цвет | HEX (примерно) | Где в логотипе |
|---|---|---|
| Оранжевый | `#F8941A` | левая полоса |
| Красный | `#D6181D` | нижняя диагональ |
| Бирюзовый | `#209485` | верхняя диагональ |
| Зелёный | `#50A957` | правая полоса |
| Тёмный графит | `#353A40` | фон |
| Белый | `#F7FAFC` | надпись |

## Заметка для дизайнера
Референсы каруселей (`referensy/karuseli/`) в основном в бордо, кремовом и чёрном. У логотипа четыре ярких цвета на графите. При сборке `vizual-stil.md` брать подачу из референсов, а цвета — из логотипа и брендбука. Своих цветов поверх бренда не добавлять. Если нужен один акцент, выбор согласовать с директором.
