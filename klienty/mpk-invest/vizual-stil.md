# Визуальный стиль mpk-invest

Источник: брендбук `brendbuk/brendbuk.md` и `brendbuk/tokens.json` (от директора, 22.11.2026).
Оригинал: https://claude.ai/artifact/AmyTU4qzDWrwKhtHLmwaMS

Стиль: серый «каменный».
- Графитовый фон, фактура щебня.
- Обесцвеченные фото техники, карьеров, вагонов.
- Белые заголовки.
- Одна оранжевая «искра» на слайде, как каска Щебіньчика.

## Палитра
| Цвет | HEX | Роль |
|---|---|---|
| graphite | #1C1C1C | фон, затемнение фото |
| stone-700 | #2E2E2E | плашки, карточки |
| stone-500 | #5A5A5A | линии, контуры иконок; не текст |
| stone-300 | #A6A6A6 | второстепенный текст |
| stone-100 | #E4E4E2 | светлые таблички фракций; текст на них graphite |
| ink | #FFFFFF | заголовки, текст |
| orange | #F28C1E | 1–2 ключевых слова, иконки, стрелки |
| on-orange | #1C1C1C | текст на оранжевом (белый нельзя) |

Пропорция: ~85% серое и фото, ~12% белый текст, ~3% оранжевый.

Красный, зелёный и бирюзовый — только внутри логотипа.

## Шрифты (Google Fonts, кириллица, лицензия OFL)
| Роль | Шрифт |
|---|---|
| Главный заголовок | Oswald 700, капсом |
| Второй заголовок, текст | Montserrat 500/800 |
| Надзаголовок | Montserrat 600, капсом, трекинг 25% |

## Размеры
- Карусель: 1080×1350, поля 72px.
- Шаблоны в `brendbuk/brendbuk.md`: обложка, слайд с преимуществами, карточка фракции, обложка Reels, поздравления, последний слайд.

## Логотип и Щебіньчик
Файлы:
- `brendbuk/logo-prozrachnyy.png` — для тёмного фона.
- `brendbuk/personazh-shchebinchyk-prozrachnyy.png` — Щебіньчик.

Правила логотипа:
- Ставится слева вверху обложки, только на тёмном фоне.
- Вариант для светлого фона (`logo-dlya-svetlogo-fona.png`) брендбук не предусматривает. Не использовать.

Правила Щебіньчика:
- Внешность не менять.
- Уместен в сторис, лёгких рубриках, советах, поздравлениях.
- В строгих B2B-каруселях не обязателен.

## Нельзя
- Яркие, пастельные, синий, фиолетовый цвета.
- Оранжевый фон на весь слайд.
- Каллиграфия в заголовках, цифрах и контактах.
- Цветные фото без обесцвечивания.
- Эмодзи вместо иконок.
- Перерисовывать логотип и Щебіньчика.
