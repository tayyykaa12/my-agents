# Референсы каруселей для mpk-invest

От директора, 23.11.2026. Чужие посты — только ориентир по механике. Тексты, факты и оформление свои: по брендбуку МПК Інвест (графит, белый Oswald, оранжевый акцент; логотип только на тёмном).

## 01 — квиз «Насколько хорошо ты разбираешься в бетоне?» (@simvol_beton)
- **Механика:** проверь себя.
  - Обложка: вопрос-вызов, «уровень: средний», «5 вопросов».
  - Дальше вопрос → варианты → ответ на следующем слайде.
- **Цифры поста:** ~3,8 тыс. лайков, ~7,4 тыс. отправок, ~100 репостов. Самое сильное — **отправки**: квиз пересылают коллегам, чтобы проверить их.
- **Визуал:** светлый фон, крупный узкий капс (красный + чёрный), вырезанная машина на белом, иконка-чеклист «5 вопросов», логотип сверху.
- **Как взять для МПК:** «Наскільки добре ви знаєтеся на щебені? 5 питань».
  - Вопросы только по фактам из прайса и брифа, плюс общеизвестные: фракции, что такое ЩПС, чем отсев отличается от песка, щебень продаётся в тоннах, как считать объём.
  - Правильный ответ — на следующем слайде.
  - Финал: «Скільки правильних? Напишіть у коментарях» или «Замовте доставку» (один призыв).
- **Оформление:** графит вместо белого (брендбук). Фото техники обесцвеченное, иконки линейные, вместо красного — оранжевый.

## 02 — сезонный вопрос «Пошёл первый снег. Можно ли ещё заливать бетон?» (@ufa_meka_beton)
- **Механика:** привязка к сезону или событию плюс практический вопрос, который у покупателя возникает прямо сейчас. Ответ — в карусели.
- **Цифры поста:** 13 лайков, 2 репоста, то есть слабо. Механика рабочая, но подача обычная (ИИ-картинка, «как у всех»).
- **Визуал:** белый фон, капс чёрный + красный, плашка-вопрос, вырезанный ИИ-самосвал под снегом.
- **Как взять для МПК:** «Перший сніг: чи можна завозити й відсипати щебінь узимку?».
  - **Внимание:** советы по зимним работам — технические утверждения. Писать только общие и бесспорные вещи или брать их у клиента. Обещания вроде «возим круглый год» — только с подтверждения клиента.
- **Когда:** сразу при первом снеге (неделя 3–4 декабря), иначе теряется актуальность.

## Выводы
- Сильнее всего работает то, что хочется **переслать**: квизы, шпаргалки, чек-листы. Это совпадает с целью месяца (охват и пересылки).
- Сезонные темы нужно ставить в план заранее и публиковать в день события.
- Обе идеи передать `strateg` для недель 3–4 и `kopirayter-mpk` для текстов.
